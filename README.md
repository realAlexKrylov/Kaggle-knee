# RSNA Knee Abnormality Detection — бронза

Ранговый ансамбль четырёх CNN для поиска 12 патологий на МРТ колена.
[Соревнование на Kaggle](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection), соло, ~6 400 команд.
Публичный скор — 0.958 macro ROC AUC.

## Задача

- 12 находок: ACL, MCL, Medial / Lateral Meniscus, Medial / Lateral / PF OA, Effusion, Synovitis, Baker's cyst,
  Contusion, Fracture. Метрика — macro ROC AUC.
- Скрытый тест — 1 284 исследования: 30 % идут в паблик, 70 % в приват.
- Инференс только офлайн, не дольше 9 часов на 2×T4.

## Решение

| модель | архитектура | TTA |
|---|---|---|
| Raptor-384 (nartaa) | CoAtNet + MIL, 94 окна по 3 среза | анатомическое зеркало |
| Raptor-224 (nartaa) | та же сеть, 224 px, другое поле обзора | анатомическое зеркало |
| R6 (heliosli) | ConvNeXt-small + MIL, 4 фолда | flip |
| S6 (nartaa) | ConvNeXt-small, кропы вокруг колена, другие метки | — |

Бленд для каждой находки:

```
raptor  = 0.60·rank(384) + 0.40·rank(224)
compact = 0.58·rank(R6)  + 0.42·rank(S6)
final   = w·raptor + (1 − w)·compact      # w = 0.46; Lateral OA 0.16, PF OA 0.56, Synovitis 0.76, Baker's 0.31
```

- **Разнообразие моделей вместо подгонки весов.** S6 обучена на других метках, чем R6, и даёт основной прирост.
  Raptor-224 ошибается на других исследованиях, чем 384.
- **Веса выбраны без подгонки под лидерборд.** По симуляции разница двух похожих сабмитов шумит на паблике на ±0.0005,
  это ниже точности табло. Доли моделей выбраны по модели корреляций их ошибок.
- **Отказоустойчивый инференс.** Каждая модель — отдельный процесс с лимитом времени. Если модель упала на исследовании,
  её вес на нём делится между остальными. Массовый сбой останавливает ноутбук, а не даёт тихо урезанный сабмит.

```
Raptor-384 ─► Raptor-224 ─► S6 (≤ 3.5 ч) ─► R6 (до 8.3 ч от старта) ─► ранговый бленд ─► submission.csv
```

## Эксперименты

| что проверял | результат |
|---|---|
| 4 модели, зеркальная TTA для Raptor-224 | 0.958 |
| то же без S6 (контроль) | ниже, чем с S6 |
| больше доля S6; веса находок ближе к 0.5 и дальше от 0.5 | 0.958, ниже основного варианта |
| + полное поле 384 px для Raptor-384 | падал на скрытом тесте |
| доли моделей по модели корреляций ошибок | **лучший результат, финал** |
| финал с другими весами находок | вторая финальная попытка |
